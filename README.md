A modern, full-featured e-commerce product catalog frontend built with Next.js, Apollo Client, and Tailwind CSS. This application demonstrates advanced GraphQL queries with filtering, pagination, and sorting capabilities.

## ✨ Features

- **Advanced Filtering** - Filter products by category, brand, price range, and rating
- **Server-Side Pagination** - Efficient pagination with page navigation
- ⬆**Dynamic Sorting** - Sort products by price, rating, name, or date
-**Search Products** - Real-time search by product name
- **Fully Responsive** - Mobile-first design with drawer filters on mobile
- **Optimistic UI** - Smooth loading states and skeleton screens
-  **Modern Design** - Beautiful UI with Tailwind CSS
-  **Type Safety** - Full TypeScript support with generated types
-  **Performance** - Apollo Client caching and optimization

## Tech Stack

| Technology | Purpose |
|------------|---------|
| **Next.js 14** | React framework with App Router |
| **Apollo Client** | GraphQL client for data fetching |
| **TypeScript** | Type safety and better DX |
| **Tailwind CSS** | Utility-first CSS framework |
| **Lucide React** | Beautiful icon library |

##Quick Start

### Prerequisites

- Node.js 18+
- npm or yarn
- Backend API running (NestJS GraphQL server)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/nextjs-graphql-filter-pagination
cd nextjs-graphql-filter-pagination

# Install dependencies
npm install

# Run the development server
npm run dev


NEXT_PUBLIC_API_URL=http://localhost:3000/graphql
